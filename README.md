# 🦙 jpxcodex/xforx

Model ini adalah turunan dari **Llama 3.2** yang telah disesuaikan dengan *system prompt* khusus untuk menjadikannya asisten yang ramah dan hangat. Dibuat menggunakan [Ollama](https://ollama.com) dan dipublikasikan di [Ollama Registry](https://ollama.com/jpxcodex/xforx).

## ✨ Fitur

- Berbasis Llama 3.2 (model ringan dan cepat)
- System prompt: *"You are a friendly assistant..."* → selalu merespons dengan nada positif dan membantu
- Parameter inferensi optimal untuk percakapan santai (temperature 0.7, top_p 0.9)
- Siap pakai dengan satu baris perintah

## 📦 Prasyarat

Pastikan [Ollama](https://ollama.com/download) sudah terinstal di sistem Anda.

## 🚀 Cara Menggunakan

### Langsung jalankan
```bash
ollama run jpxcodex/xforx
